设计优化与确认规范实现：
• 240×320 物理比例：精准适配 ST7789 竖屏，布局严格不溢出；全界面统一采用 Google Fonts（Oswald 标签 + Chakra Petch 仪表数字 + Roboto Mono 数据）。
• 3大页面架构：旋钮旋转仅在 Page 0 功能页 ↔ Page 1 传感器诊断 ↔ Page 2 系统设置 之间切换；Page 0 展示何种功能（P-GEAR / 轨迹记录 / 码表）完全由设置项 FUNCTION MODE 决定。
• P-Box 直接踩油门触发：静止就绪（READY）状态下，一旦点击【🚗 踩油门加速】（对应真机车速增加或 G > 0.15G），自动进入高频加速计时并在达 100km/h 时锁定成绩；短按可随时复位准备下一次加速。
• 轨迹记录短按开启、长按停止：在 Track 界面，短按开启录制（REC 呼吸红灯、SD 写入红灯）；长按（或点击【按住长按】按键）停止记录并安全落盘。
