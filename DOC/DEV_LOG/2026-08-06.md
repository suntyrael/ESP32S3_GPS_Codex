- **决策**：SD 引脚表以原理图坐标解析结果为准，作废旧文档矛盾值。
- **决策**：芯片 ID 一律"宽松校验"（候选列表），不硬编码单一值拒绝启动（应对替代料）。
- **决策**：I2C 用新 master 驱动（`driver/i2c_master.h`），ADC 用 oneshot+curve fitting（旧驱动 v6 已删）。
- **决策**：版本跟随 `release-v6.1`，官方新 release 发布后再评估升级（C-01b）。

- **决策**：驱动走"句柄式 + 组件化优先 + BSP 封装"（esp_lvgl_port），不做设备树/跨平台 HAL。
