# 开发日志规范（DEV_LOG）

**目录：`DOC/DEV_LOG/`** —— 开发日志独立保存于此，随 git 版本化，禁止 gitignore。

## 规则

1. **命名**：`YYYY-MM-DD.md`（UTC+8 本地日期，一天一个文件，可多次追加）
2. **提交**：每次代码 commit 时，将对应开发日志**同批提交**，保证日志 ↔ 代码状态一一对应
3. **CI 结果**：GitHub Actions 构建结论（通过/失败/错误摘要）记入当天日志，链接为 workflow run
4. **语言**：中文，技术名词可英文
5. **只追加**：历史事实不改写；发现错误以"勘误"条目追加

## 模板

```markdown
# 2026-XX-XX 开发日志

## 会话
- 时间：HH:MM ~ HH:MM
- 目标：

## 完成事项
- [ ] 事项 1（说明）

## 关键决策
- **决策**：…
- **理由**：…

## 改动文件
- `path/to/file` — 改动说明

## CI 结果
- workflow run：<名称>/<run id>
- 结果：✅ 通过 / ❌ 失败（附错误摘要）

## 问题与对策
- **问题**：…
- **对策**：…
- **状态**：待解决 / 已解决（提交 xxx）

## 待办
- [ ] …
```
