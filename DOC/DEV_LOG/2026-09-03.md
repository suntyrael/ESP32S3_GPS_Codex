### 2. 3 大页面体系与按键契约（严格落地确认规范）
- **旋转编码器（EC11）**：无论何时旋转，严格只在 3 个大页面间顺序循环切换：
  `[Page 0: 主功能页] ↔ [Page 1: 传感器诊断页] ↔ [Page 2: 系统设置页]`。
- **Page 0 子视图模式**：由 Page 2 设置项中的 `FUNCTION MODE` 唯一决定：
  - `0 = MAIN_PAGE_PBOX`（P-GEAR 直线加速测试）
  - `1 = MAIN_PAGE_LOGGER`（TRACK REC 轨迹记录仪）
  - `2 = MAIN_PAGE_BIKE`（BIKE COMP 自行车码表）
- **按键契约**：
  - **短按**：P-Box 模式下一键清零复位（RESET）；轨迹记录模式下开启录制（防误触：开启短按）；码表模式下暂停/继续；设置页循环步进修改当前选中项的值。
  - **长按（>900ms）**：轨迹记录模式下停止录制并安全落盘 GPX（防误触：长按停止）；码表模式下单次里程与极速清零（Trip Reset）；诊断页/设置页快速返回 Page 0 (HOME)。
  - **双击**：显式消费事件，防止事件队列残留或未定义动作。

### 3. Google Fonts 字体在 LVGL 9 中的全量生成与集成
- 使用官方字体转换工具 `lv_font_conv`，将 HTML 中指定的 3 款 Google Fonts 转换为 LVGL 9 点阵字库源文件：
  - `main/font_chakra_petch_48.c`（48px 科技仪表大数字）
  - `main/font_chakra_petch_16.c`（16px 仪表关键数值）
  - `main/font_oswald_14.c`（14px 页面标题与设置项名称）
  - `main/font_oswald_12.c`（12px 状态栏辅助说明与小标签）
  - `main/font_roboto_mono_12.c`（12px 诊断页等宽对齐数据与时钟）
- **致命排查（字体空白问题）**：定位到 `lv_font_conv` 默认开启 RLE 压缩（`bitmap_format = 1`），而在 LVGL 9 中未启用解压模块时直接返回 NULL，导致“只显示白色底色没有字符”。重新采用 `--no-compress` 生成未压缩直读点阵（`bitmap_format = 0`），字形从 Flash 直读，字符秒级渲染；全字体挂载 `Montserrat_14` 作为安全 Fallback。

### 4. 消除多线程并发死锁与 Task Watchdog 崩溃
- **问题排查**：分析用户提供的 Task Watchdog 崩溃日志（`IDLE0 did not reset watchdog, CPU 0: app_task`），定位到 `app_task` 在按键触发后直接跨线程调用 `lv_label_set_text()`，引发 LVGL 内部渲染队列竞争死锁。
- **架构解耦**：彻底重构外部交互接口，`app_task` 仅原子读写业务状态变量，严禁跨线程碰任何一行 LVGL 控件代码；界面元素统一由 LVGL 内部任务 `ui_timer_cb`（50Hz / 20ms）周期渲染。
- **调度平衡**：将 `TASK_PRIO_INPUT` 从 7 调至 4，避免高优先级忙等饿死 IDLE 空闲任务。

### 5. P-Box 直线加速测速状态机与假数据清零
- **起步触发判定**：引入真实起步判定双保险（离开零点 `speed_kmh >= 1.5 km/h` 或持续有效推力 `acc_x_g > 0.25g`），彻底消除桌面晃动误触发。
- **防假起步超时保护**：起步后持续 2.5 秒内车速仍 < 2.0 km/h，自动强制重置回 `READY` 待机，计时归零 `00.00s`，绝不原地空跑。
- **0.01s 平滑步进计时**：采样频率提升至 100Hz，UI 刷新提升至 50Hz (20ms)，采用微秒硬件时钟 `esp_timer_get_time()` 格式化 `%05.2fs`，呈现丝滑毫秒跳动。
- **假数据清除**：0-60/0-100/400m 初始清零显示 `--.-- s`，真实测得时填入并锁定；Peak G 接入真实传感器动态峰值统计。

### 6. G 值雷达物理坐标轴校正与美化
- **排查反向 bug**：原代码中误将左右位移 `px` 绑定给 Y 轴加速度、上下位移 `py` 绑定给 X 轴加速度，导致“左右晃红点上下跑、上下晃红点左右跑”。
- **坐标对齐**：水平位移 `px` 严格由横向 X 轴（`g_lat`）驱动，垂直位移 `py` 严格由纵向 Y 轴（`g_long`）驱动；红点初始精准居中于 `(24, 24)`；圆盘容器清零内边距（`pad_all = 0`），修复十字线断裂和色块变形。

### 7. 传感器诊断页与设置页排版深度优化
- **消除重叠**：重新精确分配诊断页 4 张卡片的 Y 坐标（IMU 66px, MAG 50px, BARO 50px, GNSS 80px），卡片间严格保持 4px 均匀间距，彻底消除 BMP388 与 GNSS 的重叠现象。
- **新增遥测数据**：
  - 六轴 LSM6DSR 增加 **LIN ACC 线性加速度**（重力分离后的纯动态推力，橙色高亮）。
  - GNSS 卡片新增**海拔高度（ALT）与实时地速（SPD）**行。
  - BMP388 气压计温度升级为 **IMU + MAG + BARO 三传感器实时融合平均温度**。
- **设置页防贴底**：优化 7 个条目的行距（每行高 32px，间隙 4px），末行底部留有 20px 缓冲，升级为 Oswald 14px 加粗大字体，完整显示绝不贴底。
- **码表与轨迹清零**：轨迹记录总里程、时间、爬升、点数全部清零（`0.00km` / `00:00:00` / `+0m` / `0PTS`）；码表坡度与垂直速度初始清零为 `0.0%` / `+0.0m/s`，并接入真实气压差分动态计算。

## 关键决策

1. **字体位图采用未压缩格式（Plain Bitmap）**：
   - 决策：放弃 RLE 压缩，采用 `bitmap_format = 0`。
   - 理由：4MB Flash / 2MB PSRAM 资源充裕，未压缩格式无需解压模块，直读点阵，杜绝因解压管道返回 NULL 导致的空白屏，且显著提升刷新率。
2. **外部任务与 LVGL 绝对线程解耦**：
   - 决策：外部输入任务只改状态标志，UI 渲染完全收敛在 `ui_timer_cb`。
   - 理由：LVGL 9 非线程安全，跨线程加锁容易在多核抢占中引发死锁或看门狗饥饿；解耦后架构极度清晰、零死锁风险。
3. **P-Box 假起步 2.5 秒超时自动复位**：
   - 决策：起步 2.5 秒内车速未离开零点自动复位回 READY。
   - 理由：手持晃动无法避免瞬时加速度波动，加入车速确认与假起步超时可以保证桌面操作与车上静止时不会错误空跑。
