## 完成事项

### 1. 开机长时间白屏 Bug 彻底根除（硬件锁电平 + 显存首帧同步刷新）
- **根因定位**：
  - 硬件 LCD 背光由 NPN 数字三极管 Q3（DTC123JCA）驱动，基极直连 GPIO 9；ESP32-S3 复位与 ROM Bootloader 期间 GPIO 9 默认具有弱上拉或浮空，分压超过 0.7V 导致上电第 0 毫秒背光被提前点亮。
  - 原程序直到 `app_main` 靠后位置的 `lcd_driver_init` 才配置背光引脚；在此之前的串口打印、NVS 初始化、I2C 多传感器延时探测期间，屏幕液晶未初始化但背光全开，呈现长时间刺眼白屏。
  - `lcd_driver_init` 在配置 ST7789 寄存器后显存为空白即强开 50% 背光，而后续 `ui_init` 异步调度，首帧渲染滞后。
- **架构闭环修复**：
  - `main/lcd_driver.h` / `main/lcd_driver.c` 新增 `lcd_backlight_early_off()`，将 GPIO 9 强制配置为输出低电平（输出 0 + 使能内部下拉），在 `main/app_main.c` 第一行以最高优先级执行，截断开机漏光。
  - `lcd_driver_init()` 配置 LEDC PWM 时初始占空比严格保持为 0（背光保持熄灭）。
  - `main/ui.c` 在 `ui_init()` 结尾加锁调用 `lv_refr_now(disp)` 强制同步完成首帧整屏渲染并通过 DMA 写入 ST7789 显存，延时 `LCD_POWER_ON_DELAY_MS (20ms)` 待液晶稳态后再平滑开启背光。
  - `sdkconfig.defaults` 增加 `CONFIG_ESP_MAIN_TASK_STACK_SIZE=8192`，保障 main 任务执行同步渲染具备充裕栈空间。
  - 上电白屏持续时间彻底降为 0ms。

### 2. 设置界面三层分层有限状态机重构
- **编码器事件解耦**：`input_task` 仅上报波轮旋转事件，不在驱动层修改页面模式，模式与光标切换全权由应用层按状态机流转。
- **分层状态机运转**：
  - `SETTING_STATE_PAGE`（页面浏览态）：波轮旋转顺序循环切换 3 个大页面（Page 0 ↔ Page 1 ↔ Page 2）；短按波轮激活光标态。
  - `SETTING_STATE_CURSOR`（光标选择态）：波轮在 1~9 项之间上下移动光标，选中的卡片以 2px 高亮边框显现；短按根据条目类型进入编辑、直接切换或进入校准。
  - `SETTING_STATE_EDIT_FUNC`（Function Mode 轮转编辑态）：短按 Item 1 进入，波轮旋转轮转切换 `P-GEAR` ↔ `TRACK REC` ↔ `BIKE COMP`，短按确认退出并即刻联动更新主页。
  - `SETTING_STATE_CALIB`（传感器校准流程态）：独立校准弹窗，严格按时序递进。
- **顶部固定标题栏与无滚动条独立滚动列表**：
  - 根视口 `content` 自身关闭滚动，顶部 `SETTINGS` 标题与 `1/9` 索引绝对常驻固定（Y=0 ~ Y=18），彻底消除滚动到底部再往上滚看不到标题的 bug。
  - 独立内部容器 `list_container`（Y=20 ~ Y=284）负责 9 项卡片平滑滚动，显式关闭滚动条显示（`LV_SCROLLBAR_MODE_OFF`），光标移动回第 1 项时调用 `lv_obj_scroll_to_y(0)` 绝对复位。

### 3. 设置项扩展至 9 项与全量 NVS Flash 持久化存储
- **扩展设置条目与默认对齐**：
  - Item 1: `FUNCTION MODE`（P-GEAR / TRACK REC / BIKE COMP）
  - Item 2: `COLOR THEME`（SUNLIGHT / DARK）
  - Item 3: `GPS RATE`（10 HZ / 18 HZ / 1 HZ / 5 HZ）
  - Item 4: `GNSS MODE`（GPS+BDS / ALL GNSS / GPS ONLY）
  - Item 5: `BRIGHTNESS`（50% / 75% / 100% / 25%，**默认值 50% 与硬件基线 `LCD_BL_DEFAULT_PERCENT` 严格对齐**）
  - Item 6: `AUTO SLEEP`（3 MIN / 5 MIN / NEVER / 1 MIN）
  - Item 7: `RTC AUTO SYNC`（ON / OFF，新增项）
  - Item 8: `ALT AUTO CALIB`（ON / OFF，新增项）
  - Item 9: `SENSOR CALIB`（START >）
- **新建持久化模块 `main/settings_store.h` / `main/settings_store.c`**：
  - NVS 命名空间 `"settings"` 保存 8 项有效系统配置，设置界面短按确认后毫秒级落盘；开机启动在 `ui_init()` 与 `app_main()` 优先加载上次数值，**断电重启绝不上电重置**。
  - NVS 命名空间 `"cal"` 保存 IMU 陀螺零漂、加速度偏置、磁力计硬铁偏移与软铁缩放矩阵，开机在 `sensors_init()` 自动载入并应用到采样数据流。
- **两大自动校准业务功能落地**：
  - **`RTC AUTO SYNC`**：在 `main/gnss.c` 增加 `gnss_set_rtc_auto_sync(bool)`，开关置于 ON 时 GNSS 获得有效 3D 定位后自动调用 `settimeofday()` 同步系统 RTC 硬件时钟。
  - **`ALT AUTO CALIB`**：在 `main/bmp388.c` 扩展支持 `bmp388_calibrate_altitude()`，在 `main/sensors.c` 导出汇聚接口；开机后当 GNSS 处于 3D 定位良好状态（`VDOP ≤ 2.5` 且卫星数 ≥ 5）时自动以 GNSS 高度反算海平面基准气压 $P_0$（QNH）校正气压计海拔基准；**开机仅自动校准一次（`s_alt_calibrated_this_boot = true`），后续绝不重复校准**。

### 4. 彻底废除假进度，实现 100% 物理闭环传感器校准引擎
- **彻底清除 UI 伪造时间进度代码**：将 `main/ui.c` 中基于系统流逝时间硬算进度的代码连根拔起，界面进度条与提示文案 100% 直接读取底层 `sensor_task` 物理采样计算输出的状态快照。
- **IMU 真实零偏校准【策略 A 振动清零惩罚】**：
  - 严苛静止判据：三轴陀螺角速度绝对值 $< 3.5^\circ/s$（$3500\text{ mdps}$）且加速度合力模长严格在 $1\text{G} \pm 0.06\text{G}$（$940 \sim 1060\text{mg}$）以内。
  - **振动即清零惩罚**：一旦检测到手抖、晃动或桌面敲击振动，底层累积采样立即清零，进度条被打回 0%，红字警示 `VIBRATION DETECTED! KEEP STILL!`。
  - 必须在平稳台面上连续、纯净静止平放满 2 秒（40 帧采样），进度条才线性涨至 100% 并解算真实零偏。
- **地磁计空中 8 字真实校准【静止死锁 0% + 30 秒超时保护】**：
  - 静止不动死锁 0%：动态追踪三轴磁场极差 $(\Delta X, \Delta Y, \Delta Z)$，静止平放极差小于底噪（$< 12\mu\text{T}$）或象限数 $<2$ 时，进度条恒为 0%，红字提示 `STATIC! MUST ROTATE IN 8-SHAPE!`，放在桌上 100 小时也不会上涨。
  - 三维八象限立体角真实覆盖驱动：只有在空中做真实 3D 翻转、覆盖 $\ge 7$ 个立体角象限且跨度充分时，进度才按真实覆盖率上涨。
  - **30 秒超时事件机制**：设定 30 秒硬超时保护（`MAG_CALIB_TIMEOUT_MS = 30000`），超时未达标判定失败，红字提示重新校准，绝不保存未收敛数据。
  - 必须完成 8 字校准（100% 达成）后才允许保存退出，未完成前短按不响应；任意阶段长按随时安全取消。
- **双 5 秒倒计时准备期**：IMU 校准前 5s 倒计时准备，地磁校准前额外给出 5s 倒计时准备，给用户充足时间拿稳设备。

### 5. 按键状态机重构与手感提升
- **彻底删除“中按（MIDDLE）”**：业务层无中按场景，此前在 250ms~900ms 造成按键死区与被吞；重构为二元判定：`<800ms` 为短按（包含双击），`≥800ms` 为长按。
- **长按满 800ms 即刻响应机制**：
  - 按键按下持续满 800ms 瞬间**立即发射事件并执行底层响应，绝不等松手**；
  - 引入单次边沿锁存标志 `long_triggered`，按住不放绝不连击或重复触发，松开手指时静默复位，绝不误触短按或双击。
- **编码器 300ms 窗口**：防抖与未转动清零超时收敛到 `main/config.h`（`ENC_WINDOW_MS = 300`）。

## 关键决策

1. **设置页面采用“固定顶部标题栏 + 独立内部列表滚动”**：
   - 决策：根视口关闭滚动，标题栏与页码常驻挂在顶层，9 个条目包裹在专用透明 `list_container` 中滚动并关闭滚动条显示。
   - 理由：彻底杜绝标题栏被卷出视口的缺陷，界面干净清爽，兼顾任意多设置项扩展。
2. **校准物理采样收敛至 `sensor_task`，UI 仅读状态快照**：
   - 决策：真实加速度合力检测、陀螺角速度方差判定、磁场三维八象限立体角统计全部在 `sensor_task` 每次硬件采样时执行，UI 线程仅轮询快照。
   - 理由：杜绝多任务跨线程同时读写 I2C 总线引发的总线竞争与死锁，严格遵循 D-02 单一写者原则，从根本上杜绝伪造假进度。
3. **长按按键采用单次锁存立即响应（One-Shot Edge Latch）**：
   - 决策：按满 800ms 立即动作，松手静默复位。
   - 理由：大幅提升人机交互体验，操作反馈零延迟，彻底杜绝长按松手时误触发短按。
