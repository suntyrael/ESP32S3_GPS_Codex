## 完成事项

### 1. 根因破案与电子罗盘 3D 倾角补偿航向解算落地
- **根因分析**：
  - 诊断页 LIS2MDL 磁力计卡片的 `lbl_mag_heading` 刷新时错误绑定了 `(double)(g->valid ? g->course_deg : 0.0f)`（GPS 地面航向角），根本没有读取磁力计传感器数据。
  - 在室内校准或静止无 GPS 定位时，`g->course_deg` 恒为 0.0，导致即使用户在空中做完 8 字校准，诊断页读到的始终是 000.0°。
  - 原代码中的 `(CAL: GOOD)` 仅代表磁力计通信在线（`st->mag.valid`），与实际校准状态无关。
- **架构闭环修复**：
  - 在 `main/sensors.h` 汇聚层结构体 `sensors_mag_t` 中扩充 `float heading_deg`（0.0° ~ 359.9°）。
  - 在 `main/sensors.c` 采样任务（`sensors_update`）中基于 LSM6DSR 估计的重力加速度矢量 $\mathbf{g}$，通过空间切平面向量投影对校准后的磁场数据进行 **3D 倾角补偿（Tilt Compensation）**；在极限立起或大动态冲击状态下优雅平滑退化为 2D 水平面罗盘解算，严格遵循 D-02 单一写者契约。

### 2. 移除 `(CAL: GOOD)` 并显示东南西北 8 方位
- 将 `main/ui.c` 诊断页磁力计卡片中的 `(CAL: GOOD)` 彻底移除。
- 采用 45° 扇区中心划分算法，根据实时解算的罗盘航向角动态映射并显示 8 方位缩写：`N`（北）、`NE`（东北）、`E`（东）、`SE`（东南）、`S`（南）、`SW`（西南）、`W`（西）、`NW`（西北）。
- 格式化输出为 `HEADING:  %05.1f°  %-2s`，等宽字体下严格对齐，清爽舒展。
- 同步优化自行车码表页（Bike Computer）：静止或无 GPS 定位时自动无缝回退至磁力计电子罗盘航向，原地转动车把航向即可即时响应。

### 4. 磁力计机身坐标系极性回正与全姿态平放到垂直无奇异点航向解算
- **实测现象定位**：
  - 现象一：南北指向正确，但东西方向反向（朝东显示 W、朝西显示 E）。
  - 现象二：设备物理指向保持不变，由平放改为垂直放置时，移动过程中指向发生变化或跳变。
- **根因分析**：
  - 东西反向：机身横向 X 轴极性定义相差一个负号，将 `MAG_AXIS_X_SIGN` 从 1 改为 -1 即可彻底回正；
  - 平放到垂直移动过程漂移：旧代码直接以机身顶部为前向进行俯仰倾角补偿，当抬起至接近 90°（垂直放置）时，$1 - uy^2 \rightarrow 0$ 触发极限奇异点并退化至 2D 平面计算（忽略了垂直放置时向前视线已转移至屏幕背面，且 Y 轴已变质为地磁垂直分量），导致抬起过程中航向剧烈漂移。
- **架构闭环重构**：
  - 在 `main/config.h` 中将 `MAG_AXIS_X_SIGN` 修正为 -1（映射矩阵：$X_{\text{dev}}=-m_1, Y_{\text{dev}}=-m_0, Z_{\text{dev}}=-m_2$）。
  - 在 `main/sensors.c` 中重构全姿态 3D 空间正交切平面解算法：
    1. 通过 $\mathbf{E} = \mathbf{m} \times \mathbf{u}$ 提取严格水平正东单位向量 $\mathbf{e}$；
    2. 通过 $\mathbf{N} = \mathbf{u} \times \mathbf{e}$ 提取严格水平正北单位向量 $\mathbf{n}$；
    3. 构建动态前向视线参考向量 $\mathbf{f}_{\text{ref}} = (0, uz, -uy)$（平放自动对应机身顶部，垂直自动平滑对应机身背面视线，全过程数学严格与重力向量正交）；
    4. 通过 $\text{atan2}(\mathbf{f}_{\text{ref}} \cdot \mathbf{e}, \mathbf{f}_{\text{ref}} \cdot \mathbf{n})$ 直接解算航向，从 0° 到 90° 平放到垂直平滑连续，航向绝对锁死不飘。

### 6. PCB 背面贴装极性根因排查、全姿态平放与垂直自适应锁死及 GPS 地磁偏角自动补偿
- **实测现象定位**：设备物理指向不变时，水平平放与竖直立起放置，地磁指向方向不一致（相差整整 180°）。
- **根因分析**：
  1. 实物与 PCB 正式图确认 LSM6DSR（IMU）贴装于 PCB 背面，当正面朝上平放时芯片正面朝向地面，支持力推动芯片背面，芯片原始 $OUTZ < 0$。原 `IMU_AXIS_Z_SIGN` 为 1 未反转，导致重力天顶向量在平放时算成指向地心 $(0, 0, -1)$，而竖直立起时长边向上为 $(0, 1, 0)$，重力向量方向在平放与竖立间发生 180° 翻转颠倒；
  2. 磁力计与加速度计未在同一严格右手系对齐。
- **架构闭环修复**：
  1. `main/config.h` 中修正 PCB 背面贴装右手系：`IMU_AXIS_X_SIGN = -1, Y = 1, Z = -1`；
  2. `main/sensors.c` 中修正平放静态校准（减 1000mg），并重构平放到竖直立起的重力加权前向自适应平滑解算；
  3. `main/sensors.h` / `c` 中集成 WMM 双二次曲面中国/东亚高精度（$<0.5^\circ$）地磁偏角与全球偶极子查算算法，GPS 定位后自动计算地磁偏角并输出地理真北航向 `heading_true_deg`；
  4. `main/ui.c` 诊断页磁力计卡片扩展 `HDG(T): xxx.x° DIR (D:±xx.x°)`，码表页静止时使用真北航向无缝衔接运动轨迹。

## 关键决策

1. **航向解算收敛于 `sensors.c` 汇聚层，UI 仅读快照**：
   - 决策：在 `sensor_task` 物理采样后立即完成 3D 倾角补偿并存入 `sensors_state_t`。
   - 理由：保证整个固件（诊断页、码表页、轨迹记录仪）均可共享经统一滤波校准的电子罗盘航向，严格遵循 D-02 单一写者契约，UI 任务无繁琐浮点向量运算。
2. **GNSS 卡片采用工整对称的 3 字母字段标签（ALT/SPD/HDG）**：
   - 决策：高度取整数米、速度保留 1 位小数、航向取整数度（如 `ALT: 486m | SPD:24.5 | HDG:072°`）。
   - 理由：兼顾 240px 竖屏像素宽度与信息密度，格式完全对称，两端留有充裕安全间距。
